# Imágenes de Plexglobe

## 1 · Capturas reales (lo que más vende)

Las que empiezan por el nombre del cliente: `olivanova`, `cterra`, `tripcazador`,
`listora`, `jtm`, `crypto-dashboard`, `training`, `oliva-dashboard`.

**Añade tres capturas buenas de cada web que entreguéis.** Es la única fuente que
demuestra en vez de afirmar, y la única que la competencia no puede copiar.

## 2 · Fondos de marca generados por código

Los `fondo-*.webp`. Se regeneran con:

    python3 fondos.py

42 piezas: 7 texturas × 3 paletas × 2 formatos.

| textura | qué comunica |
|---|---|
| `red` | el motivo de marca: nodos conectados |
| `topografia` | profundidad, análisis |
| `semitono` | gráfico, contundente en miniatura |
| `orbitas` | sistema, movimiento |
| `flujo` | orgánico, sin dos iguales |
| `prisma` | estructura, construcción |
| `malla` | degradado suave, para titulares largos |

Cambia la semilla en `fondos.py` y salen infinitas variantes distintas.
Cero coste, cero licencia, y son solo tuyas.

## 3 · Banco externo — SOLO si hace falta

**Pexels** (CC0) y **Unsplash** permiten uso comercial sin atribución.
Descárgalas tú desde la web (no por API: la API sí exige crédito visible).

Reglas para no meter la pata:

- Solo texturas, arquitectura, escritorios, abstracto.
- **Nunca** personas: ni Pexels ni Unsplash garantizan cesión de imagen, y la
  responsabilidad de comprobarlo es de quien publica.
- **Nunca** para simular clientes, equipo o resultados. Eso es publicidad engañosa.
- Pásalas por el duotono de marca (`estilos.duotono`) para que no canten a stock.

Búsquedas que encajan con la marca: *terracotta texture*, *concrete wall warm*,
*minimal desk overhead*, *architecture curve shadow*, *linen paper macro*.
